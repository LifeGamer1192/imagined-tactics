# hex-sim

ブラウザで遊ぶ、ヘックスのターン制戦術ゲームです。歴史シミュレーション「Imagined Chronicles」のセーブ（.histsim）を読み込み、その状態から戦略と戦闘を遊びます。日本の戦国と、中国の春秋戦国の2つの版があります。

- 見本のセーブが4つ入っているので、すぐに始められます。
- 遊び方は、画面右下の「？」から読めます。
- セーブはブラウザの中に保存されます。別の端末へは、セーブの画面の「書き出し」で移せます。
- 地図の記号、地形、兵の駒、背景の絵は AI（Gemini）で生成したものです。

このリポジトリには、ビルドした公開物だけを置いています。
