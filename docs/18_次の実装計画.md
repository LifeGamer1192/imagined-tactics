## P64〜（2026-10-22 のユーザーの指示「難易度に『非常に難しい』『鬼難易度』を追加」から。企画のみ・未実装）

### 考え方
- 今の難しさは2本立て：戦略（`strategy.json` の `difficulty`：自分の収入・自分の領の守り・相手が自分を狙う度合い・相手の兵の初めのレベル・空き領を攻める度合い）と、戦闘の相手の考え方（`ai.json` の `levels`、国モードでは戦略の難しさと同じ段を使う）。
- 戦闘の考え方は、むずかしいがすでに試した中でいちばん強い（先読み・大将狙い・気力の値打ち・補助の時機などは試して強くならず、切ってある。docs/15 の 2026-10-18 の項）。だから上の2段は、**考え方はむずかしいのまま、数の不利（ハンデ）で難しくする**のを基本にする。考え方の上積みは、測って強くなったものだけを入れる。
- 「非常に難しい」＝上手な人がよく考えれば勝てる。「鬼」＝ほぼ理不尽。数で押され、四方から狙われる。

### 数の案（ふつう／むずかしい／非常に難しい／鬼）

- 戦闘の考え方：非常に難しい・鬼とも、むずかしいの考え方を使う（`ai.json` の `levels` に `veryHard`・`oni` を足し、むずかしいの重みを引き継ぐ）。鬼だけ、むずかしいの重みの「急所狙い」（`kill`・`weakTarget`・`leaderKill`）をさらに強め、弱った駒と将を逃さない。
- 単独の戦い（1戦だけの遊び方）の「相手：」にも2段を足す。戦略の数（収入など）は関係しないので、戦闘の考え方と `aiBattleStat` だけが効く。
- 数はすべて data/system に置き、測って直す。

### 画面
- 難しさを選ぶ所（国を選ぶ画面・ima-rpg から始める画面・単独の戦いの「相手：」）に「非常に難しい」「鬼」を足す。鬼は朱色の文字にして、選ぶと一言の注意（「相手は数で上回り、四方から攻めてきます」）。
- 選んだ段は、戦略画面の上の欄（今は「勢力10・3か月・ふつう」）に出す。鬼は朱色。
- 天下統一の年表（P57）に難しさを書く。鬼で統一したら、特別の称号の一文を足す。

### 測り方（入れる前に）
- 戦略：見本4つで、自分の国をおまかせにして10年回す（難しさごとに数回）。自分の国が残る割合・領の数の変わり方を比べ、ふつう＞むずかしい＞非常に難しい＞鬼 と、はっきり段になっていることを確かめる。鬼でも、おまかせの自国がすぐ（2年以内に）滅ぶほどではない数にする。

## P68〜（2026-10-22 のユーザーの指示「技・軍略を教える」「王を変える」から。企画のみ・未実装）

### 技・軍略を教える（伝授）

ねらい：訓練に「誰に何を教えるか」の選ぶ楽しさを足す。ただし、全部の技・軍略を持った個性の無い駒が量産されないようにする。

**決まりの柱（量産を防ぐ5つの枷）**
1. **枠**：教わった技・軍略（伝授）は、将は2つ、兵は1つまで。いっぱいなら、どれかを忘れないと新しく覚えられない。もとから持つもの（役職・兵種・持ち越し）は枠に数えない。
2. **相性**：教われるのは、その駒が使える形の技・軍略だけ。
   - 技：近い技（射程1）と遠い技（射程2以上）で分け、もとの技に同じ形のものがある駒だけ。装填の要る技（`reload`）は鉄砲の系統だけ、水の上の技（`needsWater`）は水軍だけ、騎の技は得意地形が騎の駒だけ。
   - 軍略：将は知略が軍略の格に応じた値以上。兵は軍略の兵（使番・間者の系統）だけが軍略を教われる。ほかの兵は技だけ。
3. **秘伝**：当主だけの役職・特別な役職・上級の兵種にしかない技・軍略は教えられない。上級の役職の軍略は、教える側がその役職の熟練度を上限まで上げているときだけ。
4. **時間と成否**：教えるのに月がかかり（技・軍略の格で1〜3か月）、その間は教える側も教わる側も行動済み（訓練と同じ扱い）。成功の見込みは、教える側の知略（技なら武力も）と教わる側の知略、間柄（師弟・義兄弟・主従は大きく上がる。hist-sim の縁 `ties` を使う）で決まる。失敗しても経験値は入る（今の訓練と同じぶん）。
5. **借り物**：教わったばかりの技・軍略は、気力が2割多くかかり、戦いで5回使うと「身につく」（ふつうの気力になる）。（案：身につくまでは、教えた将と離れると毎月まれに忘れる。厳しすぎるなら入れない）

**誰が誰に**
- 将→将：同じ領にいる自分の将どうし。1人の将が1か月に教えられるのは1人だけ。
- 王（当主）→将：「直伝」。成功しやすく、教わった将の忠誠が上がる。
- 将→兵：自分の配下の兵だけ、格2以上の兵だけ、1隊に1つ。兵が昇進しても、新しい兵種で使える形なら残る。
- 兵→将：なし（兵から将に取り立てたときの技の引き継ぎ（P59）はそのまま）。

**ほかとの関わり**
- 武将の情報欄・列伝の窓に、伝授の欄（誰から・身についたか）を出す。戦闘の技・軍略のボタンに「伝」の印。
- 相手の国も、ときどき（難しさが上がるほど多く）教え合う。
- 数はすべて `strategy.json` の `teach` に置く（枠・月数・成功率・気力の上乗せ・身につく回数）。
- セーブ：将に `taught: { id, kind: 'skill' | 'tactic', from, uses }[]`、兵にも同じ形で1つ。古いセーブは空。

**画面**
- 将の欄に「教える」ボタン。押すと窓：左に教われる相手（同じ領の将と配下の兵）、右に教えられる技・軍略（相性の合わないものは灰色で理由つき：「遠い技を持たない」「知略が足りない」「秘伝」など）。選ぶと、かかる月・成功の見込み・枠の残り・忘れるもの（枠がいっぱいのとき）を出して確かめる。
- 月の終わりに結果（成功・失敗）を記録と窓で。

### 王（当主）を変える

**方法は2つ**
1. **跡継ぎを決める**：当主が亡くなったときに継ぐ人を、前もって決めておく（今は「跡継ぎの役の人、いなければ最も名のある将」）。いつでも変えられ、費用は無い。決めた人が跡継ぎになり、戦略画面に「跡継ぎ」の札。
2. **譲る（代替わり）**：今すぐ当主を替える。
   - 選べるのは、自分の国の将で、15歳以上、深手・諸国巡り中・休養中でない人。
   - 前の当主は「隠居」：将のまま残る（当主の役職は、その人に近い並の役職に戻す。ima-rpg で主人公を王にしたときの仕組み（`imarpg.ts` の当主の付け替え）を共通にして使う）。采配の当主の上乗せは新しい当主へ移る。
   - 新しい当主は、国の政体と大きさに合った当主の役職になる（今の決まり）。
   - 代わりに払うもの：その月は国じゅうの将が行動済み。新しい当主より名声（fame）の高い将は、忠誠が下がる（下がり方は名声の差）。跡継ぎに決めておいた人へ譲るなら、下がり方は半分。
   - 一度譲ったら、24か月は譲れない。
- 記録と年表（P57）に「〇〇が当主となる（譲り）」、滅亡の窓（P60）の歩みにも残る。
- 当主が亡くなったときの代替わり（今の `succeed`）も、役職の付け替えを同じ共通の仕組みに揃える（今は役職が変わらない）。

**入れないもの（今回）**：家臣の謀反・下剋上（忠誠の低い強い将が当主を奪う）。面白いが大きいので、別の P にする。

| P68 | 伝授の中身 | 枠・相性・秘伝・月と成否・借り物。`strategy.json` の `teach`。将と兵に `taught`。戦闘で使える・気力の上乗せ・身につく |
| P69 | 伝授の画面 | 「教える」の窓、結果の知らせ、情報欄・列伝・技のボタンの印、相手の国の伝授 |

## P72〜（2026-10-25 のユーザーの指示「捕虜と登用」「史実の分かれ道」を検討。企画のみ・未実装）

### 捕虜と登用（P72・P73）

今：戦いで倒された武将は深手（数か月戦えない）になり、隣の自分の領へ退く。兵だけは、戦いの終わりにこちらにいれば捕まえることがある（`caught`）。

**捕まる**
- 戦いで倒された敵将（退却は除く）は、勝った側に捕まることがある。見込み（案）：基本30%、退く先の自分の領が無い（囲まれた・最後の領）+30%、その領を奪われた +10%、臆病（逃げ足）−10%、機敏の差で少し増減。守備頭・当主は捕まらない（当主は護衛が逃がす。最初の版では当主の捕縛は扱わない）。
- 捕まった将は「捕虜」：もとの勢力のまま、戦えず、動けず、捕らえた家の領（捕らえた領、なければ本拠）に置かれる。その領を取り返されると、解き放たれて国へ戻る。毎月まれに（2%）自分で逃げる。

**自分が捕らえたとき（戦いのあとと、その後いつでも）**
- 窓に捕虜の顔絵・能力・特性・縁と、選べる3つ（と保留）：
  - **登用する**：家臣にする。見込みは、もとの家への忠誠（縁込み）・特性（公正・武人は断りやすい、強欲・野心は応じやすい）・こちらの家に縁のある武将（義兄弟・友・昔の主）・こちらの当主の魅力と名声で決まる。窓に見込みを出す。成功すると忠誠が低め（−1）で仕える（寝返りやすい）。失敗すると捕虜のまま（翌月から見込みは下がる）。もとの家が滅んでいれば応じやすい。
  - **解き放つ**：もとの家へ帰す。こちらの当主の名声が上がり、相手の家の心証が上がる。帰った将は、こちらへの「恩」を持つ（のちに寝返り・登用の見込みが上がる）。
  - **処断する**：その将は世を去る。相手の家の心証が大きく下がって戦になり、その将と縁のある武将はこちらの当主を仇とする。こちらの家の公正・優しい武将は忠誠が下がる（残酷な当主なら下がらない）。
  - **保留**：捕虜のまま置いておく（あとで選べる。捕虜の一覧から）。
- 捕虜の一覧：国の欄（領の情報）に「捕虜n人」、押すと一覧と上の窓。

**相手が捕らえたとき（自分の武将が捕まる）**
- 知らせが出る。相手の当主の性格で決まる：仁・武勇なら解き放つことが多く、知略なら登用を持ちかけ（自分の将が寝返ることがある）、苛烈なら処断することがある。
- 取り戻す方法：その領を攻め取る、または身代金（兵糧）を払う（外交の窓に「捕虜を返してもらう」）。

**ほかとの関わり**：結果の窓（P55）と祝いの窓に「捕らえた将」。年表に「〇〇を捕らえ、家臣とする」。史実の人物の顔絵がそのまま出る。数は `strategy.json` の `captive`。セーブに `c.captives`。

### 史実の分かれ道（P74〜P76）

今：史実の出来事は年月が来ると起きる。自分の家が関わる領の動き（割譲・併合など）だけは、受けるか断るかを選べる（HistoryChoice）。人の死（戦死・暗殺・自害・処刑・病没）や合戦の損耗は、自分の家でもそのまま起きる。

**1) 兆し（自分の家の人の死を防ぐ）P74**
- 自分の家の武将・当主が、暗殺・戦死・自害・処刑で世を去る出来事の1〜2か月前に「兆し」の窓（例：「明智光秀の様子がおかしい」「刺客の噂」）。選ぶ：
  - **備える**：その武将（と護衛1人）はその月の終わりまで行動済み・兵糧を少し払う。見込み（案）70%で出来事は起きず、「史実と違う道」になる。外れた側の人物（謀反人など）はその家を去るか、深手になる。
  - **史実のままにする**：起きる。
- 病没は防げないが、名医（金瘡医・典薬衆などの兵がいる領）がいれば、数年延びることがある。
- 自分の家にかかわらない出来事は、今までどおり起きる。

**2) 史実の合戦を戦う P75**
- 自分の家が出る合戦の出来事（「三方ヶ原の戦い」「赤壁の戦い」など、軍の損耗が書いてある出来事）が来たら、窓で選ぶ：
  - **戦う**：その合戦を、出来事の場所の戦場で、両家の武将で実際に戦う（攻め手・守り手は出来事どおり）。勝ち負けで、出来事の損耗と名声の増減を、勝った側に合わせて置き換える。
  - **避ける**（籠城など）：損耗は無いが名声が下がる。
  - **史実のままにする**：今までどおり。

**3) 史実の目標 P76**
- 自分の家が仕掛ける側の戦の出来事（今は起こさない）を、「史実では、この頃〇〇へ攻め込む」という目標として出す。決まった月までにその領を取ると、名声と兵糧（と家宝を考えてもよい）。取らなくても罰は無い。

**分かれたことの記録**
- 「史実と違う道」になった出来事を記録し、年表に「異」の印。そのあとの出来事は、要る人物や家がいなければ起きない（今の決まりに、人物の生死も足す）。天下統一の窓に「史実と違う道 n件」。
- どの出来事を分かれ道にするかは、hex-sim の側で、出来事の種類と死因（暗殺・戦死など）と自分の家の関わりから自動で決める（hist-sim のデータは変えない。もっと上手に選びたければ、あとで hist-sim と相談して目印を足す）。

| P73 | 捕虜の画面 | 結果の窓・捕虜の一覧・選ぶ窓（見込みつき）・知らせ・年表 |

## P77（2026-10-26 のユーザーの指示「相国の効果の検討」。企画のみ・未実装）
