# 次の実装計画（P19〜）

2026-10-16 のユーザーの指示から。P ごとに、試験 → push（`source`）→ 公開 をする。

| P | 内容 | 要点 |
|---|---|---|
| P19 | 戦場を六角形にし、6つの向きから攻める | 戦場の形を、六角形のマスを六角形に並べた盤にする（半径7、169マス）。盤の6つの辺（東・北東・北西・西・南西・南東）のうち、攻めてきた方角の辺に攻め手、反対の辺に守り手・城・城壁を置く。方角で攻めやすさが変わる（山の側から攻めると苦しい、など）。川は盤の15%まで、海は25%まで。近くに川・海があれば盤に入れる |
| P20 | 城を取って勝つ | 攻め手が天守（城のマス）に居続けて2〜4巡（城の強さで決まる）で攻め手の勝ち。時間切れのとき天守に攻め手がいれば攻め手の勝ち。思考も、攻め手は天守を目指し、守り手は天守を守る |
| P21 | 地形と天気の厚み | 荒れ地（砂漠など）・雪原（氷河・寒冷地）を足す。すべての地形と天気に、攻撃の種類（近接・弓・鉄砲・騎馬の突撃・火・水・軍略）ごとの強まる・弱まるを付ける |
| P22 | 柵・物見櫓・砦の門を置き、壊す・使う | 使っていなかった絵の柵・物見櫓・砦の門を戦場に置く。門・柵は攻め手が壊せる（耐久）。櫓・物見櫓は乗った側が使える（攻め手が取れば攻め手のもの）。地形の効果も付ける |
| P23 | 配置を自分で決める | 自動で並べたあと、配置場所の中で少し動かせる。「配置完了」で戦闘が始まる |
| P24 | 国モードの戦いで退く | 「退く」ボタン。退くと重い罰（兵の一部を失う、兵糧を失う、守り手なら領を失う） |
| P25 | 本拠を移す | 費用が多くかかり、2〜3か月かかる命令 |
| P26 | 史実の出来事（その1） | 済。仕組み・知らせ・安全な効果（死去・当主の死去・兵の減少・兵糧・本拠の移り）。自分の家への効果は知らせだけ |
| P27 | 史実の出来事（その2：外交） | 戦・停戦・同盟・同盟の解消・従属 |
| P28 | 史実の出来事（その3：領の動き） | 併合・割譲・分裂・独立。自分の家にかかわるときの扱い（受ける・断る）も決める |


P19〜P26 は 2026-10-17 までに済み（docs/15_実装状況.md）。
