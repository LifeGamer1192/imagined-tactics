## 戦闘の思考（P9）

`src/ai/ai.ts`、`src/ai/personality.ts`、設定は `data/system/ai.json`。

**性格**：武将の特性（hist-sim の23種類）と能力から、7つの軸を出す（−1〜+1）。兵は、率いる武将の性格で動く。

| 軸 | 高いと | 主に上げる特性 |
|---|---|---|
| 攻撃性 | 前に出る、打って出る、粘る | 勇敢、武人、野心 |
| 慎重さ | 危険を避ける、地形を選ぶ、早めに退く | 臆病、疑り深い、賢明 |
| 統率 | 兵をまとめる、武将どうし足並みをそろえる | カリスマ、統一者、公正 |
| 知略 | 妨害・状態異常の軍略を使う、軍略役を狙う | 天才、賢明、学者 |
| 苛烈さ | 弱った相手を仕留める、味方を巻き込むのをいとわない | 残酷、強欲 |
| 仁 | 回復・補助を使う、味方を巻き込まない、主君を守る | 優しい、敬虔、寛大 |
| 武勇 | 敵の武将を狙う、倒される危険を軽く見る | 公正、武人、勇敢 |

**判断の軸**：移動できるマス × 使える技・軍略の組み合わせを、次の軸で採点する。性格は各軸の重みを変える。

| 軸 | 内容 |
|---|---|
| 攻める価値 | 与えるダメージ、倒せるか（攻撃力の高い相手ほど価値が高い）、弱った相手、武将、軍略役、主君のそばの敵 |
| 反撃の危険 | 受ける反撃。倒しきれるなら反撃は来ないものとして減らす |
| 脅威 | 次の敵ターンに受けそうなダメージ。倒されそうなら大きく減点 |
| 地形 | 命中・回避の補正が良い場所 |
| まとまり | 采配範囲の中にいる、前衛は主君と敵の間に立つ、武将どうし離れすぎない |
| 間合い | 射撃・軍略役・回復役は敵に隣り合わない。弓は射程ぎりぎりを保つ |
| 構え | 下の「構え」に応じた位置取り |
| 支援 | 回復（深手の味方・武将を優先）、補助（状況に合うものだけ）、妨害、状態異常 |
| 気力の節約 | 消費の大きい軍略を無駄撃ちしない |

**構え**：部隊（武将とその兵）ごとに決める。

| 構え | いつ | 動き |
|---|---|---|
| 前進 | 攻め手で、敵がまだ遠い。守り手でも猛攻の武将、戦力が大きく上回るとき | 敵に向かって詰める。後衛と、前に出ない武将は3マス手前まで |
| 交戦 | 敵が近い | 攻撃を優先する |
| 守備 | 守り手で、敵がまだ遠い（時間切れなら守り手の勝ちなので） | その場を保ち、良い地形を選ぶ |
| 退却 | 武将の体力が少ない。慎重な武将ほど早く、猛攻の武将ほど粘る | 武将は敵から離れ、兵は踏みとどまる |

攻め手は時間切れが負けなので、巡が進むほど急ぐ（危険を気にしなくなり、武将も前に出る）。

## セーブ（P12）

- 戦略パートの状態を保存できる。枠は「自動」（月が変わるたび）と手動3つ。ブラウザの中（IndexedDB）に入る。
- ファイル（.hexsim）への書き出しと読み込みができる。タイトル画面の「セーブファイルを選ぶ」は .histsim と .hexsim の両方を受け付ける。
- タイトル画面に「つづきから」が出る（保存があるとき）。
- 保存して続けても、通しで遊んだ場合と同じ歴史になる（乱数の状態も保存している）。
- 戦闘の途中は保存できない。合戦（1戦だけ）のモードには保存するものが無い。

## 見た目の強化（2026-10-10）

- 戦場と戦略マップを、和紙と墨の絵柄に描き直した（`src/render/paper.ts`・`ink.ts`・`crest.ts`・`battleView.ts`・`strategyView.ts`）。
- 戦略マップは、セーブのセルの形から海岸線・川・領の境・勢力の境を描く。領の選択は、クリックした場所のセルから決める。
- 地図の記号（山・森・町）は hist-sim の絵を流用（`public/art/map/`）。
- 兵の駒の絵は、生成したシート（3×3）を `tools/art-cut.mjs` で切り分ける。元のシートは `art-src/unit/`、切り分けた絵は `public/art/unit/<jp|cn>/<兵種の番号>.webp`。絵を足したら `node tools/art-manifest.mjs`。
- 絵の無い兵種は、名前の2文字の駒のまま（絵が無くても動く）。
- 済み：兵の駒は日本版・中国版とも 50種すべて（元のシートは各6枚）。橋・沼の記号も生成した絵に替えた（城壁・柵の絵は `public/art/map/sym_wall`・`sym_palisade` にあるが、まだ使っていない）。残り：背景。

- 無料のウェブ版で保存するときは、画像を画面内に出してから保存ボタンを押す（画面の外の画像は保存されない）。
- 顔の絵は当面作らない。
- 見た目の確認：`node tools/shot.mjs <出力先>`（戦闘と戦略マップの画面を撮る）。

## 観戦の操作と、戦略マップの hist-sim 合わせ（2026-10-10）

- 戦闘中に、観戦（両方おまかせ）と手動を切り替えられる。観戦で始めた戦いを手動にすると、攻め手を操作する。
- おまかせの陣営が動く速さを5段階で選べる（1手ごとの間：900・500・260・110・20ミリ秒）。選んだ速さはブラウザに覚える。
- 上の2つのボタンは、速いときに押せなくならないよう、ほかの表示とは別に置いて必要なときだけ書き換える（`renderCtl`）。確認は `node tools/watch-check.mjs`。
- 戦略マップは、hist-sim の地形描画をそのまま移して使う（`src/render/hist/`：hist-sim の `src/render/` の terrain・symbols・geometry・style・palette・sprites と `src/gen/types.ts` の写し。読み込み先だけ直してある）。hist-sim 側を直したら、写し直す。
- 絵柄は、セーブに入っている hist-sim の設定（`world.settings.visual`）に合わせる。見本の3つは「古地図」。
- 国名は領土の形に沿って大きく書く。題字（世界の名前と年月）、方位、町の絵と名前も hist-sim にならう。
- hex-sim だけの表示は、本拠の紋、領ごとの武将の人数、選んだ領・移動できる領・攻められる領の色。
- hist-sim にあって、まだ無いもの：占領中の斜線、戦線の赤い線、軍の駒、川の名前、遺跡・名所の絵。
- `simplex-noise` を依存に足した（地形描画の写しが使う）。

## 戦闘の記録の細かさと、攻撃のエフェクト（2026-10-11）

### 記録の細かさ（簡易・通常・詳細）

- 戦闘画面の「記録：簡易・通常・詳細」のボタンで選ぶ（速さ・音のボタンの下の行）。速さとは別。選んだ細かさはブラウザに覚える（`hexsim.logLevel`。はじめは通常）。手動でも観戦でも同じに効く。戦いの途中で切り替えると、すでに出ている記録も、その細かさで出し直す。
- 記録の元データ（`st.log`）は1つで、表示だけを変える（`src/ui/battleLog.ts`）。
  - 簡易：これまでどおり、1件1行。直近60件。
  - 通常：1つの行動が、見出し（どちらの陣営の、どの武将の、どの兵が、どの技・軍略を）＋字下げした行（だれに、命中・会心・外れ、ダメージ、体力がいくつからいくつ、反撃とその結果、付いた状態、倒れたか、使った気力、得た経験値）。移動は「どこからどこへ（地形と、列・行）」。直近40の行動。
  - 詳細：通常に加えて、計算式と途中の値。命中率の内訳（基本・機敏の差・技の補正・自分と相手の地形・騎の相手・特性・櫓・雨・霧・夜、上限下限、出目）、ダメージ（威力 × 攻撃 ÷ 防御 × 特効・反撃・雨の日の火 → 切り捨て → × 乱数 × 会心 × 盾 → 四捨五入）、攻撃と防御の成り立ち（武力 × 2、状態変化、采配範囲外）、会心率と出目、状態異常の確率と出目、軍略のダメージ（知略・相手の知略と防御・耐性）、成功率、回復量。待機も出す。直近24の行動。
- 式に出す値は、計算で実際に使った値。計算の関数が内訳を返す形にした（`src/rules/combat.ts` の `hitParts`・`damageParts`・`atkParts`・`defParts`・`tacticParts`・`successParts`・`healParts`。これまでの `hitChance`・`skillDamage` などは、その答えだけを返す）。計算結果と、乱数を引く順番は変えていない。
- 記録に足したもの（`src/battle/engine.ts`）：行動の見出し `act`（`n` が、その行動で続いた記録の数）、移動 `move`、1撃の内訳 `strike`、軍略の相手ひとりぶんの内訳 `tactic.on`。内訳は記録の `d` に入る。これまでのキー（`hit`・`miss`・`tactic.hit` など）は、そのまま残してある。簡易の記録は、足したキーを除いて出す。
- 記録の欄は、通常・詳細では少し広くなる（上の情報欄の高さの上限を 76% → 66% → 54% に下げる）。左の線と名前の色が陣営（攻め手は朱、守り手は藍）。
- 気を付けること：戦いのあとのレベルアップの乱数の種に、記録の件数（`st.log.length`）が入っている（`src/battle/result.ts`）。記録の件数が増えたので、同じ戦いでも、レベルアップで伸びる能力の出目は前と変わる（戦いそのものの結果は変わらない）。

### 攻撃のエフェクト

- どの技がどのエフェクトかは、技の番号で決める表（`src/ui/fxTable.ts`）。表に無い技と、武将の通常攻撃は、射程1なら斬撃、2以上なら矢。
  - 近接：斬る（刀・太刀・鉈）、突く（槍・懐の刃・騎馬の突進）、打つ（柄・盾・槌・体当たり）。会心は大きく明るい色、外れは相手のわきの空を切る薄い墨。
  - 飛び道具：矢（山なり、朱の矢羽）、投げ槍、吹き矢・手裏剣・撒き菱（小さく速い）、鉄砲・弩（速い直線の弾、発射の光と煙）、大筒（弧を描く玉と影、発射の光と煙、着弾の土煙）、岩（弧を描く玉、土煙）、火（尾を引く火の玉、着弾の炎）。外れは、相手の向こうへそれる。
  - 声・音（法螺・鬨・唄・言葉）：使った駒から輪が広がる。
  - 軍略：範囲が種類の色で光り、使った駒から同じ色の輪が出る。攻撃は朱（火は炎、単体の火矢・毒矢は飛ぶ、落石は上から岩、兵が襲うものは斬撃が交わる）、水は藍の波、回復は緑青の光と粒、補助は黄土の山形、妨害は紫の墨が垂れて渦を巻く、打ち消しは藍の輪が散る。
- ダメージの表示：当たったマスを六角形に色づけて、中に大きく数字（ダメージは朱、会心は濃く「会心」と添える、回復は緑青で「+数字」、毒は紫、外れは灰色で「外れ」）。同じマスに次の表示が来たら、前のものはマスの上に小さく積む。付いた状態・盾・退く、も小さな字で出る。
- 長さ（ミリ秒。速さの倍率を掛ける前）：斬撃・突き・打撃 320。飛び道具が届くまで、矢 150＋1マス50、投げ槍 140＋45、手裏剣など 110＋28、鉄砲 60＋14、大筒 230＋60、岩 240＋60、火 200＋55。発射の光 150、煙 620、土煙 560、炎 640、軍略の光 520、輪 420。ダメージの表示は、当たって150あとに出て 1150（付いた状態などは900）。次の一撃まで 270（直線・周囲の技は 130）。
- 速さとの関係はこれまでどおり（1・0.8・0.55・0.3・0倍。速さ5は演出なし）。ダメージの表示と煙・炎は、速くしても半分までしか縮めず、次の手は、その半分が過ぎたら打つ（表示の残りは、次の手に重なってよい）。
- 描くのは `src/render/fxDraw.ts`（絵のファイルは使わない）。演出がある間だけ描き直し、終わると止まる。地形の層は描き直さない。
- 効果音を足した：振る、投げる、鉄砲、大筒、着弾、火、水、声、補助、妨害。
- 確認：`tests/detail.test.ts`（5件。内訳から組み立て直すと実際の結果と同じになること、3段階の表示、技の表に漏れが無いこと）、`node tools/watch-check.mjs`（記録の細かさの切り替えを足した）、`node tools/fx-shot.mjs <出力先>`（時計を止めて、技ごとのエフェクトの途中を並べた画像と、記録の3段階を撮る）、`npx vite-node tools/log-sample.ts`（記録の3段階を文字で見る）。

## 舞台の外の陸地を出さない／名前の変更／指でのドラッグ／武将と兵の入れ替わり（2026-10-13）

- **舞台の外の陸地（日本の地図の朝鮮半島など）を出さない**：どの勢力の領も無い陸のかたまりは「舞台の外」として、地図では海として描き、選べず、隣り合いからも外す（`offstageCells`、`GProvince.out`、`playableMap`）。持ち主のいない領があっても、同じ陸に誰かの領があれば残る。
- **名前の変更**：武将は名前の横の「✎」、兵は名前を押して出る欄の「名前を変える」。`strategy.json` の `officer.nameMax`（12文字）まで。兵の名前を空にすると兵種の名前に戻る。兵の名前は戦いの画面・記録にも出る（`GTroop.name`）。
- **指でのドラッグ**：兵の運び方を、ブラウザ備え付けのドラッグ（指では働かない）から、ポインターの動きを自前で追う作りに替えた。マウスでも指でも同じに動く。運んでいる兵は指に付いてくる。欄の上下の端で止めると欄が送られ、隠れている武将へ運べる。軽く触るだけなら、これまでどおり兵の欄が開く。
- **武将と兵の入れ替わり**：
  - 兵 → 武将（「武将にする」）：レベル `officer.minTroopLevel`（5）以上の兵。その隊は無くなり、同じレベルの武将が同じ領に加わる。兵は連れていない。能力は並で、特性や縁は持たない。その月は動けない。
  - 武将 → 兵（「兵にする」）：当主以外で、兵を率いていない武将。同じ領の武将を選び、その下の兵1隊になる（相手に采配力と隊数の空きが要る）。名前とレベルは残る。兵種はその勢力がいちばん徴兵しやすい陸の兵。能力・特性・縁は残らず、元には戻せない。

## 何百歳もの武将が出る不具合（2026-10-14）

## BGM・絵の追加・操作の分かりやすさ（2026-10-14）

### BGM（ElevenLabs Music で生成）
- 9曲：題の曲（共通・1分）、戦略マップ（日本版・中国版・各1分）、戦闘（各1分）、勝ち・負けの短い曲（各15秒）。元は `art-src/bgm/`、ゲームでは `public/audio/bgm/*.mp3`（合わせて約8MB。使うときに読み込む）。

- 説明の小窓（`src/ui/tip.ts`・`src/ui/describe.ts`）：特性（人柄・能力への効き目・戦い方・深手）、性格（戦い方の傾向）、兵種（能力・地形・技・軍略・特技・昇格）。マウスを重ねるか、指で1度押す。

- 右下の記録欄は、枠と「記録」の見出しを付けて、地の絵と見分けられるようにした。
- 持ち主のない領を攻めたときの記録が「衛 対 → 衛の勝ち」と欠けていたのを、「在地の兵」と出るように直した。

## レベル上限の撤廃（2026-10-14）

- これまで LV30 が上限で、役職・兵種ごとに「次のレベルまでの必要経験値」を29個並べた表を持っていた。これをやめ、上限を無くした。
- 必要経験値 ＝ K ×（1 ＋（LV−1）² ÷ 36）。曲線は全員共通（LV1 を1倍として、LV7で2倍、LV13で5倍、LV31で26倍、LV100で約273倍）。役職・兵種ごとに持つのは係数 K だけ（`data/system/exp.json` の `k`、曲線の割る数は `curve.div`）。
- K は「LV30 までの合計が、もとの表と同じになる値」にした（足軽 145.82、固有 164.5、兵 u01a 53.85、u15c 148.64 など）。LV30 までの育ち方はほぼ変わらない。武将の表とのずれは平均7.5%、兵は平均18.5%（下級の兵は LV20 以降の伸びが鈍い作りだったので、30〜50%ずれるものがある）。
- 倒したときの経験値は、これまでどおり相手のレベルに比例（基本値＋加算×LV）。必要経験値はおよそ LV² で増えるので、同じレベルの相手を何体倒せば1つ上がるかは LV に比例して増え、上がり方がだんだん遅くなる（天井は無い）。
- `growth.json` の `maxLevel` を消し、`MAX_LEVEL` を使っていた所（経験値の打ち止め、武将を兵にするときのレベルの上限）を外した。
- 確認：自動テスト118件（必要経験値の曲線、足軽の LV30 までの合計、兵が LV30 を超えて上がることを追加）。

## P20 城を取って勝つ（2026-10-16）

## P28 史実の出来事（その3：領の動き）（2026-10-18）

  - 起こり（`rise`）：新しい家が、書かれた領を奪って起こる。奪われた家とは戦になる。
- 新しい家（`createRealm`）：名・色・本拠・政体はシナリオの家の決まりから、技術・兵種・兵のレベルは本家から。当主は系図のその年の人（武将としていればその武将が立つ。いなければ能力・特性・歳を系図から作る。系図が無ければ「◯◯の長」）。当主は兵を持つ（領1つにつき1隊、2〜6隊、采配力の内）。シナリオでその家に属する人物が武将としていれば加わる（自分の家の武将は除く）。兵糧150。新しい家の番号は `c.history.nations` に残り、あとの出来事（同盟など）や本文から名で呼べる。

  - 求められる（割譲・領を削る・新しい家に加わる）：受けると渡す。断ると相手の心証−40、相手と戦になる。
