# 撃破時に得られる経験値

## はじめに

- 敵ユニットを撃破した時に手に入る経験値は、倒されたユニットの[役職]/[職]とLvによって決まる。
- 倒した側のユニットとのLv差などは関係しない。
- 倒した際に与えたダメージ量も関係しない。
