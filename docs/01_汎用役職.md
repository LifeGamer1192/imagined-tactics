# 汎用[役職]/[職]

## 概要

- 汎用[役職]/[職]には男女それぞれ数種類ずつの系統があり、それぞれに下級・上級・最上級の3段階がある。
- [役職]/[職]ごとに熟練度が存在し、その[役職]/[職]でレベルアップしたときに熟練度も1上がる。
- 熟練度が上限の5に到達すると、その[役職]/[職]のパッシブスキルの一部と[軍略]/[計略]を別の[役職]/[職]へ引き継げる。
- 熟練度5は上位[役職]/[職]への[昇進]/[昇遷]の要件にもなっている。
- 男性の[軍配者]/[謀士]系と[僧]/[祝]系、女性の[女軍配者]/[女謀士]系と[尼]/[女医]系は[軍略]/[計略]が能力の全てであり、熟練度5到達で全て引き継ぎ可能なので、両系統間を行き来して[昇進]/[昇遷]させながら育成しやすい。
