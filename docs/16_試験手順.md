# 試験手順

自分の手で動かして確かめるための手順。上から順に進めると、15〜20分でひと通り確認できる。

## 0. 準備

PowerShell で次を実行する。

```powershell
cd C:\Users\guser\Desktop\ccode\hex-sim
$env:PATH = "..\node-portable\node-v22.23.2-win-x64;$env:PATH"
npm run dev
```

「Local: http://localhost:5183/」と出たら、ブラウザでそのアドレスを開く。止めるときは PowerShell で Ctrl + C。

## 3. 戦闘を自分で操作する（5分）

操作を「攻め手を操作」にして「戦闘開始」。

| # | 操作 | こうなれば正しい |
|---|---|---|
| 3-1 | 自軍（赤）のユニットをクリック | 黄色い枠が付き、右に情報と行動のボタンが出る。動けるマスが青くなる |
| 3-2 | 青いマスをクリック | そこへ移動する。「移動を取り消す」が出る |
| 3-3 | 「移動を取り消す」を押す | 元の位置に戻る |
| 3-4 | 敵（青）のユニットをクリック | 情報だけ出る（選択はされない） |
| 3-5 | 「待機」を押す | そのユニットが薄くなり、もう動かせない |
| 3-6 | 「巡を終える」を押す | 相手が1ユニットずつ動き、自分の番に戻る。右下にログが流れる |
| 3-7 | 敵の隣まで近づき、技のボタンを押して、赤くなった敵にマウスを乗せる | 右に予測（ダメージ・命中率・反撃）が出る |
| 3-8 | そのままクリック | 攻撃し、ログにダメージが出る。反撃されることがある |
| 3-9 | 軍略を持つ武将（軍配者・軍師など）を、**移動する前に**選ぶ | 軍略のボタンが押せる。移動したあとは押せなくなる |
| 3-10 | 技か軍略を選んだ状態で、右クリックか Esc | 選択が取り消される |
| 3-11 | マウスホイール、ドラッグ | 拡大縮小、スクロールができる |

見どころ
- 兵は、率いる武将の**采配範囲**（武将を選ぶと白っぽく表示される）から出ると「外」の印が付き、弱くなる。
- 武将が倒れると、その兵は戦場を離れる。
- 敵の武将を全員倒すと勝ち。20巡を過ぎると守り手の勝ち。

## 4. 思考と性格を見る（3分）

操作を「観戦（両方おまかせ）」にして「戦闘開始」。

| # | 見るところ | こうなれば正しい |
|---|---|---|
| 4-1 | 武将をクリック | 「性格：◯◯ ／ 構え：◯◯」が出る |
| 4-2 | 守り手の構え | 敵が遠いうちは「守備」。敵が近づくと「交戦」になる |
| 4-3 | 攻め手の構え | 「前進」で近づき、近づいたら「交戦」になる |
| 4-4 | 性格の違う武将どうしを比べる | 「猛攻」の武将は自分も前に出る。「慎重」の武将は兵の後ろにいて、体力が減ると「退却」になる |
| 4-5 | 回復役（金瘡医、僧・尼の武将） | 深手の味方を回復する |
| 4-6 | 弓足軽 | 敵の隣には立たず、離れて撃つ |

性格を比べやすい武将（戦国1575年）
- 織田家の**柴田勝家**・**前田利家**（勇敢 → 猛攻）と、**千利休**（天才 → 知略）
- 徳川家の**本多忠勝**（勇敢・武人 → 猛攻・武勇）と、**石川数正**（敬虔・天才 → 知略・仁）

観戦は1戦に50秒ほどかかる。

## 6. 戦略パート（5分）

編成画面の下にある「攻め手の勢力で戦略を始める」を押す。

| # | 操作 | こうなれば正しい |
|---|---|---|
| 6-1 | 自分の領（白い枠）をクリック | 右に、その領の武将の一覧が出る |
| 6-2 | 武将の行の「徴兵」を押す | 兵が1隊増え、上の兵糧が減る |
| 6-3 | 武将にチェックを入れて「移動」を押し、青くなった隣の自領をクリック | 武将が移る。その月はもう動かせない（行動済） |
| 6-4 | 武将にチェックを入れて「攻める」を押し、赤くなった隣の領をクリック | 守る武将がいれば「自分で戦う／おまかせ」を選ぶ窓が出る。いなければ、城が持ちこたえる（包囲）。記録に「囲んでいる（何%）」と出て、攻め続けて100%になると領が取れる |
| 6-5 | 「自分で戦う」を選ぶ | 戦闘画面になる。途中でやめるボタンは無く、「おまかせで決着」がある |
| 6-6 | 決着のあと「戦略マップへ」 | 勝っていれば、その領が自分の色になっている |
| 6-7 | 「月を進める」 | 年月が1か月進み、右下にほかの勢力の動きが出る。攻められたら、迎え撃つかどうかの窓が出る |
| 6-8 | ほかの勢力の領をクリック | 持ち主と関係（中立・交戦中・味方・停戦中）が出る。味方と停戦中の相手は「攻める」で赤くならない |

## 7. セーブ（3分）

戦略パートの画面で行う。

| # | 操作 | こうなれば正しい |
|---|---|---|
| 7-1 | 「セーブ」を押す | 「自動」の枠に、いまの年月が入っている |
| 7-2 | 枠1の「保存」を押す | 枠1に年月と勢力が出る |
| 7-3 | 「閉じる」→「月を進める」を数回 →「セーブ」→ 枠1の「読み込み」 | 保存したときの年月と領の数に戻る |
| 7-4 | 「セーブ」→「ファイルに書き出す」 | .hexsim ファイルが保存される |
| 7-5 | ブラウザのページを再読み込みする | タイトル画面に「つづきから」が出る。押して枠1を選ぶと続きから始まる |
| 7-6 | タイトル画面の「セーブファイルを選ぶ」で、7-4 の .hexsim を選ぶ | その状態から始まる |

## 8. 自動の確認をまとめて回す

自分で操作しなくても、次で同じ内容を機械的に確かめられる。

```powershell

node tools/smoke.mjs shots                # ブラウザで51項目を自動操作（npm run dev を動かした状態で。3分ほど）
npx vite-node tools/balance.ts 6 8        # 自動対戦144戦の集計（勝率・長さ・経験値）
npx vite-node tools/trace.ts sengoku_fid5_1575   # 1戦の経過（各巡の構えと行動）を文字で追う
```

`node tools/smoke.mjs shots` は、`shots` フォルダに各場面の画面を保存する。

## 10. 記録の細かさと、攻撃のエフェクト（3分）

| # | 操作 | こうなれば正しい |
|---|---|---|
| 10-1 | 戦闘の画面で「記録」の「簡易」「通常」「詳細」を順に押す | すでに出ている記録が、その細かさで出し直される。通常は「だれが → だれに、ダメージ（体力 いくつ→いくつ）」、詳細は命中率やダメージの式まで出る |
| 10-2 | 観戦にして、速さを変える。記録の細かさも変える | どちらも、もう一方に関わらず切り替わる。ページを開き直しても、選んだ細かさのまま |
| 10-3 | 詳細の記録の1件を、手で計算する | 「基準 ＝ 威力 × 攻撃 ÷ 防御」の切り捨て、「× 乱数」の四捨五入が、出ている数字と合う |
| 10-4 | 手動で、槍・刀・槌の技で攻める | 当たった所に、突き・斬撃・打撃のエフェクトが出る。そのあと、マスが六角形に色づいて数字が出る（1秒ほど） |
| 10-5 | 弓・鉄砲・大筒・火の技で攻める | 矢・弾・玉・火の玉が、撃った駒から相手へ飛ぶ。鉄砲と大筒は発射の光と煙、大筒は土煙、火は炎 |
| 10-6 | 軍略を使う（攻撃・回復・補助・妨害） | 範囲の光の色と、相手に出る形が、種類ごとに違う |
| 10-7 | 同じ相手に続けて当てる（攻撃と反撃、範囲の技） | 前の数字は、マスの上に小さく積まれて、重ならない |
| 10-8 | 観戦で速さ5にする | エフェクトは出ず、これまでどおり速く進む |

自動で確かめるなら次のとおり。

```powershell
node tools/watch-check.mjs                # 観戦・速さ・音量に加えて、記録の細かさの切り替え

npx vite-node tools/log-sample.ts         # 記録の3段階を、文字で見る
```
