# [兵]/[卒]一覧

## [昇進]/[昇遷]について

- 基本の[昇進]/[昇遷]条件
  - Lv10で上級が解禁
  - Lv20で最上級が解禁（最上級が存在する場合）
  - [武将]/[将]の[役職]/[職]にある熟練度の概念は無い
- 特定のアイテムを必要とする[役職]/[職]の条件
  - 該当する上級[役職]/[職]であること（レベル条件なし）＋[昇進の品]/[昇遷の宝]

## アイテム「[練兵の書]/[練兵書]」の効果

- 現在のユニットレベルに関係なく、下級→上級、あるいは上級→最上級と1段階上位の[役職]/[職]へチェンジできる。
- ユニットレベルだけが条件となっている[昇進]/[昇遷]に限られる（専用の[昇進の品]/[昇遷の宝]を要する[役職]/[職]にはなれない）。
- レベルが高くなるほど次のレベルへの必要経験値は増えるので、使うなら上級→最上級に使う方が得。
- [練兵の書]/[練兵書]×2でレベル1の最上級[兵]/[卒]にすることも可能。
- [練兵の書]/[練兵書]×1＋[昇進の品]/[昇遷の宝]でレベル1の特殊な最上級[兵]/[卒]にすることも可能。
