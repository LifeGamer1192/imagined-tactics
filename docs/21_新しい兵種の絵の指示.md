# 新しい兵種の絵の指示（0.11.0 で足した9種）

歩兵・槍・長槍・戟を4つの系統に分けたとき（P98・0.11.0）に足した9兵種の駒の絵を作るための台本。

**進み具合（2026-10-30）**：日本版 `jp_7` を持ち主の PC からウェブ版 Gemini で生成し、切り出して置いた（`public/art/unit/jp/` の9種）。素槍足軽（u19a）の槍に小さな横の刃が付いたが、作り直しを頼んでも変わらなかったので、そのまま使う。**残り**：中国版 `cn_7`・西洋版 `west_7`（その日の生成の上限で止まった）。

**今の扱い**：絵ができるまで、似た兵種の絵を仮に使う（`src/art/art.ts` の `STAND_IN`）。絵を置いて `node tools/art-manifest.mjs` を実行すれば、仮の絵は自動で使われなくなる。

## 1. 共通の決まり

- 方法・鍵・型・確かめ方は `docs/19_西洋版の絵の指示.md` の 1 と同じ（鍵はファイル・コミット・会話に書かない）。
- シートは版ごとに1枚、3×3、2048×2048。1人ずつ全身、白い紙の上、マスの真ん中、同じ大きさ。
- 見本：同じ版の兵のシート（日本版は `art-src/unit/jp_1.jpg`、中国版は `art-src/unit/cn_1.jpg`、西洋版は `art-src/west/west_1.jpg`）を1枚添える。
- 同じ系統は、上の格ほど装備が良く見えるように（例：素槍足軽 → 足軽槍組 → 鑓衆）。
- 4つの系統が一目で分かるように、武器をはっきり描く：歩兵＝刀・短い武器、槍＝人の背より少し長い槍、長槍＝人の背の2〜3倍の長い槍、戟（薙刀）＝反った刃・鉤の付いた長柄。
- 元の画像：`art-src/unit/jp_7.jpg`・`art-src/unit/cn_7.jpg`・`art-src/west/west_7.jpg`。
- 置き場と切り出し（左上から右へ、下の表の順）：
  `node tools/art-cut.mjs art-src/unit/jp_7.jpg 3 public/art/unit/jp u01d,u01e,u19a,u19c,u20a,u20b,u21a,u21b,u21c`
  （中国版は `cn_7.jpg` → `public/art/unit/cn`、西洋版は `west_7.jpg` → `public/art/unit/west`）。そのあと `node tools/art-manifest.mjs`。
