# 戦闘ルール（仮）

> 調整用のたたき台。[兵]/[卒]の能力値・技は実データ、[武将]/[将]は変換ルールで決まるため仮の値を使っている。

## 確定ルール

- ターンは陣営ごとの交互制（自軍が全ユニットを行動 → 敵軍が全ユニットを行動 → …）。
- 反撃：攻撃を受けたユニットは、反撃できる状況なら「通常攻撃」で反撃する。
  - 反撃できない状況：怯み・気絶・混乱・寝返り中／攻撃者が自分の通常攻撃の射程外／技の反撃欄が「×」
  - 反撃は攻撃側の攻撃が終わり、反撃側が生き残っている場合のみ。
- 対地・対騎の記号（対騎は、得意地形が騎の相手への当たりやすさ）
  - ◎：必中（命中判定なしで必ずヒット）
  - ○：通常
  - △：命中率が少し下がる（仮：-15）

## 仮の計算式

### 技（物理）

```
攻撃力   = [武力]/[勇] × 2 （[鼓舞]/[激励]で +49 ／ [兵糧攻め]/[断糧]で -49）
防御力   = 防御   （[堅陣]/[固陣]で +31 ／ [兵糧攻め]/[断糧]で -31 ／ 混乱中は 147）
ダメージ = 威力 × 攻撃力 ÷ 防御力 （切り捨て、最低1）
        × 乱数 0.9〜1.1 × 会心時 1.5 × [采配範囲]/[統御範囲]外 0.69（攻撃側）
命中率   = 80 + (攻撃側[機敏]/[敏] − 防御側[機敏]/[敏]) + 技の命中補正
        + 攻撃側の地形補正 − 防御側の地形補正 − △なら15
        （5〜100%に収める。◎・相手が行動不能なら100%）
会心率   = 5%（パッシブで加算）
```

引き算（攻撃−防御）ではなく割り算にしたのは、強さの差が大きくても0ダメージや一撃での壊滅になりにくく、調整しやすいため。

### [軍略]/[計略]

```
ダメージ = 威力 × (使用者の[知略]/[智] × 2) ÷ (対象の[知略]/[智] + 対象の防御) × (1 − 耐性)
耐性     = [軍律]/[軍紀] 0.34、備えC 0.10 / B 0.21、[采配範囲]/[統御範囲]外 −0.31（被ダメ増）
確率型の成功率 = (50 + 使用者の[知略]/[智] − 対象の[知略]/[智]) × (1 − 耐性) （5〜95%）
```

## 調整のつまみ

| 項目 | 今の値 | 上げると | 下げると |
|---|---|---|---|
| 攻撃力の[武力]/[勇]倍率 | ×2 | 技が全体に強くなる | 技が弱くなり、防御の高い[兵]/[卒]が硬くなる |
| 命中の基本値 | 80 | 外れにくくなる | [機敏]/[敏]の差と地形が効きやすくなる |
| △の命中減 | -15 | 騎の相手に近接が当たりにくくなる | 騎馬・戦車の有利が小さくなる |
| [軍略]/[計略]の[知略]/[智]倍率 | ×2 | [軍略]/[計略]が強くなる | [軍略]/[計略]が弱くなる |
| [軍略]/[計略]の防御側分母 | [知略]/[智]＋防御 | （防御を外すと）硬い相手にも[軍略]/[計略]がよく通る | - |
| 確率型の基本値 | 50 | 状態異常が入りやすい | [知略]/[智]差の影響が大きくなる |
| 乱数幅 | 0.9〜1.1 | ブレが大きく運の要素が増す | 計算どおりで読みやすい |

### 天気と昼夜

技の命中の式に、次の補正を足す（必中の技と、行動できない相手への攻撃は必中のまま）。

| 天気 | 効果 |
|---|---|
| 晴れ | なし |
| 雨 | 射程2以上の技の命中−10。火の技・火の[軍略]/[計略]の威力×0.8 |
| 霧 | 2マス以上離れた相手への技の命中−15 |
| 雪 | 道・橋・城・街・陣・砦・門・櫓のほかは、移動コスト+0.25。戦いの上限が2巡延びる |
| 夜 | 技の命中−5（天気と重なる） |

## 追記：式を画面で確かめる

戦闘画面の「記録」を「詳細」にすると、1撃ごとに、ここの式に入れた値と途中の値が出る（命中率の内訳と出目、威力 × 攻撃 ÷ 防御、乱数、会心、盾、状態異常の確率と出目、軍略の知略と耐性、成功率、回復量）。出る値は、計算で実際に使った値そのもの。

式の細かいところ（コードのとおり）：

- 技のダメージ：`威力 × 攻撃 ÷ 防御 × 特効 × 反撃 × 雨の日の火` を切り捨てて基準値（最低1）。それに `乱数 × 会心1.5 ×（会心に強い技なら1.25）×（盾で受けたら0.5）` を掛けて、四捨五入（最低1）。
- 采配範囲外の 0.69 は、攻撃と防御の値そのものに掛かる（攻撃側なら攻撃、防御側なら防御）。
- 軍略のダメージ：基準値（切り捨て、最低1）に乱数を掛けて、四捨五入。
- 回復量：`威力 ×（0.6 ＋ 知略 ÷ 150）×（1 ＋ 回復の特性 ÷ 100）` を四捨五入。体力の上限までしか回復しない。
- 確率型の成功率の耐性は、負の値（采配範囲外）なら 0 として扱う。

天気は、月と戦いの種から決まる（同じ種なら同じ天気）。出やすさ（重み）は、春（3〜5月）晴れ60・雨25・霧15、夏（6〜8月）晴れ55・雨35・霧10、秋（9〜11月）晴れ60・雨20・霧20、冬（12〜2月）晴れ50・雪30・雨10・霧10。夜戦は12%。
