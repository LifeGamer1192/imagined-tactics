# 兵種と軍略

妖・異獣を時代に合わせた**兵種**に、術を**軍略**に置き換えた。その対応と、あわせて変えた仕組み、数値の扱いをまとめる。
能力値・技・成長・昇進の仕組みは元のまま。名前の一覧は [00_固有名詞対応表.md](00_固有名詞対応表.md)、兵種ごとの数値は [11_兵種能力値/](11_兵種能力値/) にある。

---

## 2. 軍略（旧・術）

術はすべて軍略に置き換えた。効果・消費・威力・射程の仕組みは同じ。

| 種類 | 軍略の例（日本版／中国版） |
|---|---|
| 攻撃（単体） | 火矢／火箭、水攻め／水攻、奇襲／突襲、夜討ち／夜襲、火計／火攻 |
| 攻撃（範囲） | 焼き討ち／焚営、堤切り／決水、釣り野伏／十面埋伏、鬨の声／鼓噪 |
| 回復 | 手当て／療傷、炊き出し／犒軍、立て直し／整軍、兵站／饋糧 |
| 補助 | 鼓舞／激励、堅陣／固陣、強行軍／疾行、号令／軍令、騎乗／乗騎 |
| 妨害 | 兵糧攻め／断糧、偽報／偽書、足止め／絆馬、調略／反間、誘引／誘敵 |

あわせて変えた名前
- 軍略を使う武将の役職：軍配者 → 軍師 → 大軍師（女性は女軍配者 → 女軍師 → 女大軍師）。中国版は謀士 → 策士 → 国士。
- 軍略を使うための値：気力（中国版は士気）。
- 僧・尼の系統は、手当てと立て直しの役としてそのまま残した。

## 3. 意味づけを変えた仕組み

| 元の仕組み | 置き換え後 |
|---|---|
| 得意地形「空」 | **「騎」**（騎馬・戦車）。平地と道で速く、森・山・湿地で遅い。川・湖・海と段差には入れない。数値は [06_移動力と地形.md](06_移動力と地形.md)（仮の値） |
| 対空 ◎○△ | **対騎**（得意地形が騎の相手への当たりやすさ） |
| 弓の「空に強い」 | **騎馬特効** |
| 「山の相手に強い」 | **山岳戦**（山のマスにいる敵へのダメージが上がる） |
| 石化 | **混乱** |
| 魅了 | **寝返り** |
| 沈黙 | **攪乱**（軍略が使えない） |
| マヒ | **怯み** |
| 倒れた兵を一時的に復活させる | **敗残兵収容**（壊滅した兵を、その戦闘だけ味方として戻す） |
| 状態異常にならない体 | **兵器**（大筒・投石車など） |
| 召喚 | **徴兵** |
| 霊力 | **兵糧**（中国版は粟） |

### 得意地形の振り直し
元は「空」だった兵種を、次のように振り分けた。

| 兵種 | 得意地形 |
|---|---|
| 13番（騎馬武者・戦車）、8番の典薬衆／医官 | 騎 |
| 12番（山岳兵） | 山 |
| 2番・4番・17番・18番、1番の最上級 | 平地 |

## 4. 時代による解禁（案）

読み込んだ hist-sim の状態の年と出来事から、使える兵種を決める。条件は変換ルールの設定に出し、調整できるようにする。

| 兵種 | 解禁の条件（仮） |
|---|---|
| 鉄砲足軽系（日本） | 1543年以降、かつ鉄砲の記事がある勢力から順に |
| 大筒衆（日本） | 1570年以降 |
| 鉄甲船（日本） | 1578年以降 |
| 弩兵系（中国） | 前450年ごろ以降 |
| 騎兵系（中国） | 前307年（胡服騎射）以降。それより前は戦車系だけ |
| 戦車系（中国） | 前300年ごろ以降は昇進の上限を下げる |

## 5. 数値の扱い

元の資料に由来する数値は、すべて1〜3%ずらした。

| 対象 | 例（元 → 今） |
|---|---|
| 兵種の基礎値（采配負担・体力・気力・武力・知略・機敏・防御） | 騎馬武者の体力 470 → 483、防御 100 → 102 |
| 技・軍略の威力と消費、命中補正 | 火矢の威力 120 → 117、消費 68 → 66 |
| 効果の数値（上昇・低下の量、確率） | 攻撃力の低下 50 → 49、混乱中の防御 150 → 147、毒の確率 20% → 21% |
| 役職の能力補正・防御、昇進に必要な能力値 | 01_汎用役職の各表 |
| 必要経験値の表、撃破時の経験値の式 | 09・10 の各表 |
| 地形の命中・回避補正（20以上のもの） | 城の +30 → +31 |

決まり
- 同じ数値は、どのページでも同じ値に変わる。ページどうしの整合はそのまま保たれる。
- **20未満の小さな値は変えていない**（移動力、射程、巡の数、成長幅、小さな補正、移動コストの0.75など）。1ずらすだけで5%を超え、ゲームの性質が変わってしまうため。こうした値は、どのゲームでも使われる一般的なものでもある。
- 20〜33の値は±1（3〜5%）になる。
- レベル（Lv10・Lv20）や熟練度のような段階の数は変えていない。
- 戦闘の計算式、変換ルール、「騎」の移動コストは、もともとこのプロジェクトで決めた値なので対象外。
